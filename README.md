# lights

A project to make a (USB) christmas tree lights controller.

- Automate turning off and turning on every day, including some random element.

- Encode time into flashing the lights.

- Provide permanently powered USB charging sockets.

- Using Arduino UNO Wifi Rev 2.


## Summary

A fork of [Siddyboy/christmas-lights](https://github.com/Siddyboy/christmas-lights). An Arduino project to control USB Christmas tree lights on a daily schedule.

## What's inside

`lights.ino` (the Arduino sketch), `datasheets/`, `scans/` and `ideas.md`.

## How to view or run it

Open `lights.ino` in the Arduino IDE and upload it to an Arduino UNO WiFi Rev 2.
